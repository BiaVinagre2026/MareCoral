# Maré Coral Fitwear — kit de marca

## Arquivos
- `logo-vertical.svg` — assinatura principal
- `logo-horizontal.svg` — site, cabeçalho, etiqueta
- `simbolo-degrade.svg` / `simbolo-coral.svg` / `simbolo-rosa.svg` / `simbolo-claro.svg` — símbolo isolado (avatar, boné, favicon)

## Paleta
| Uso | Hex |
| --- | --- |
| Coral claro | #FF8A48 |
| Coral principal | #FF5A3C |
| Rosa | #F0417A |
| Areia (fundo claro) | #FFE7DF |
| Texto sobre claro | #B3543F |

Degradê oficial: `linear-gradient(140deg,#FF8A48 0%,#FF6A45 42%,#FF4F63 78%,#F0417A 100%)`

## Tipografia
Archivo (Google Fonts) — 900 no nome da marca, 700 em FITWEAR com letter-spacing 0.42em, 400 na assinatura.

## Regras
- Somente coral e rosa. Sem outras cores.
- Assinatura: "Vista o treino. Sinta a maré."
- Área de respiro mínima: altura do símbolo ÷ 2 em todos os lados.
- Tamanho mínimo do símbolo: 24px.
